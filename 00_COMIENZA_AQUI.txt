================================================================================
⚙️ PARÁMETROS CLAVE DEL BOT
================================================================================

Los principales están en .env:

SYMBOLS=...
→ Qué pares analizar
→ Ejemplo: BTC-USDT,ETH-USDT,SOL-USDT

TIMEFRAME=15m
→ Marco temporal del análisis
→ Opciones: 1m, 5m, 15m, 1h, 4h, 1d

CHECK_INTERVAL=60
→ Segundos entre análisis
→ 60 = chequea cada minuto

MAX_POSITION_SIZE=100
→ Máximo USDT por operación
→ 100 = máximo $100 por trade

MAX_POSITIONS=3
→ Máximo de operaciones simultáneas
→ 3 = máximo 3 posiciones abiertas al mismo tiempo

LINREG_LENGTH=50
→ Período de regresión lineal
→ Más bajo = más sensible a cambios recientes

ADX_THRESHOLD=25
→ Umbral mínimo de fuerza de tendencia
→ Más bajo = más operaciones, más riesgo

RISK_REWARD=2.5
→ Take Profit = 2.5x el Stop Loss
→ TP = entry + 2.5 * (entry - SL)

🎯 QUÉ ESPERAR
================================================================================

PRIMERA VEZ EJECUTANDO:

1. Dentro de 1-2 minutos recibirás mensaje en Telegram:
   → "🤖 Bot iniciado..."
   → Muestra configuración

2. Cada 60 segundos (según CHECK_INTERVAL):
   → El bot analiza todos los pares
   → Si hay señal con confianza > 50%, intenta entrar
   → Si entra, recibes notificación LONG/SHORT

3. Cuando cierra posición:
   → Notificación con PnL (ganancia/pérdida)

4. Si hay error:
   → Notificación de alerta
   → Bot intenta continuar

NO ESPERES:

- Cada minuto una operación (bot es selectivo)
- 100% win rate (el mercado es impredecible)
- Ganar cada día (puede haber rachas perdedoras)

REALIDAD:

- Operaciones cada 1-5 horas (según mercado)
- Win rate: 55-65% en condiciones normales
- Retorno promedio: 10-20% mensual (perfil moderado)
- Mejor con 100+ operaciones para ver el patrón

================================================================================
📊 INTERPRETACIÓN DE SEÑALES
================================================================================

Cuando recibes notificación LONG:

```
🟢 LONG ABIERTO - BTC-USDT
💯 Confianza: 82%
📊 Precio: 45,250.00
🛑 Stop Loss: 44,800.00
🎯 Take Profit: 46,375.00
📦 Cantidad: 0.00222
📈 R:R: 1:2.50
⚡ ✅ Cruce PDH | ✅ Bullish EMA | ✅ ADX fuerte | ...
```

Significado:
- Confianza 82% = Score calculado por indicadores
- Cantidad 0.00222 BTC ≈ $100 (según MAX_POSITION_SIZE)
- R:R 1:2.50 = Por cada $1 que arriesgamos, ganamos $2.50
- Razones = Qué indicadores confirmaron

🔧 DEBUGGING CON MONITOR
================================================================================

Si no ves operaciones, ejecuta:

```bash
python monitor_pairs.py
```

Verás tabla como esta:

```
PAR          SEÑAL        CONF    PRECIO      SL          TP          RIESGO      R:R
BTC-USDT     🟢 LONG      82%     45250.00    44800.00    46375.00    0.99%       1:2.50
ETH-USDT     ⚪ NONE      0%      -           -           -           -           -
SOL-USDT     🔴 SHORT     75%     98.50       99.80       95.25       1.32%       1:2.50
```

Si ves "NONE" en todos:
1. El mercado está lateral (sin tendencia)
2. ADX bajo (tendencia débil)
3. Espera a que aparezca una tendencia clara

Si ves señales pero bot no entra:
1. Puede estar en límite de MAX_POSITIONS
2. Puede haber entrado hace poco (espera)
3. Revisa logs: python main.py

⚠️ ERRORES COMUNES
================================================================================

❌ "Olvidé colocar punto en parámetros"
WRONG: MAX_POSITION_SIZE=100
RIGHT: MAX_POSITION_SIZE=100.0

❌ "Compartí .env en GitHub"
→ Las credenciales son públicas
→ Cualquiera puede usar tu API
→ Revoca las keys inmediatamente

❌ "Cambié el código y ahora no funciona"
→ Crea una rama en GitHub: git checkout -b backup
→ Si falla, vuelve a la versión original

❌ "El bot entra pero cierra inmediatamente"
→ Probablemente hit SL
→ Revisa si ADX está bajo (mercado lateral)
→ Aumenta LINREG_MULT o ADX_THRESHOLD

❌ "Quiero cambiar MAX_POSITION_SIZE a mitad"
→ En Railway, edita variable en dashboard
→ Guardará automáticamente en próximo deploy
