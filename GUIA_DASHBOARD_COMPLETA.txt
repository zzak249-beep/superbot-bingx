================================================================================
INSTALACION EN RAILWAY
================================================================================

OPCION A: REEMPLAZAR main.py CON main_dashboard.py
───────────────────────────────────────────────────

1. Ve a railway.app → Tu proyecto

2. Click "Code" o "Files"

3. Abre main.py

4. Selecciona TODO (Ctrl+A) → Elimina

5. Copia TODO de main_dashboard.py → Pega

6. Click "Save"

7. Railway redeploya (30-60s)

8. El bot está corriendo + generando dashboard

OPCION B: MANTENER AMBOS
────────────────────────

Si quieres tener:
   • main.py = Bot actual
   • main_dashboard.py = Bot con dashboard

1. En Railway, crea un nuevo servicio:
   Click "+"  → "Service"
   Nombre: "bot-dashboard"
   Repo: tu repo GitHub
   Root: /
   Command: python main_dashboard.py

2. Configura variables igual que bot principal

3. Deploy

Resultado: 2 bots corriendo (análisis duplicado pero stats independientes)

COMO USAR EL DASHBOARD
================================================================================

PASO 1: BOT CORRIENDO
──────────────────

El bot genera automáticamente dashboard.html

PASO 2: DESCARGAR dashboard.html
────────────────────────────────

1. Railway → Files
2. Busca "dashboard.html"
3. Click "Download" (icono ↓)

   1. Railway → tu servicio
   2. Click "View Logs"
   3. Busca menciones de "dashboard"
   4. Puede haber un link directo

──────────────────────────

1. Guarda el archivo en tu computadora
2. Haz doble click en dashboard.html
3. Se abre en navegador
4. ¡Listo! Ves todas tus estadísticas

PASO 4: ACTUALIZAR DATOS
────────────────────────

El dashboard se regenera cada iteración del bot

Para ver datos nuevos:
   1. Recarga la página (F5 o Ctrl+Shift+R)
   2. O descarga el archivo HTML nuevamente

================================================================================
PROBLEMAS Y SOLUCIONES
================================================================================

PROBLEMA: No veo dashboard.html
─────────────────────────────────

Solución:
1. Verifica que main_dashboard.py esté corriendo
2. Ve a Railway → Deploy Logs
3. Busca: "Dashboard guardado"
4. Espera 1-2 ciclos (180-360 segundos)
5. Recarga Railway Files

PROBLEMA: Los datos no se actualizan
──────────────────────────────────────

Solución:
1. Recarga la página (F5)
2. Limpia cache (Ctrl+Shift+Supr)
3. Descarga dashboard.html nuevamente
4. Abre en navegador fresco

PROBLEMA: Los trades no aparecen
──────────────────────────────────

Solución:
1. Verifica que el bot esté corriendo (status = Active)
2. Busca en logs: "LONG SIGNAL" o "SHORT SIGNAL"
3. Si hay signals: bot está funcionando
4. Dashboard se actualiza cada 180s
5. Espera próximo ciclo

PROBLEMA: Win rate muy bajo (< 30%)
─────────────────────────────────────

Posibles causas:
   • CHECK_INTERVAL muy bajo (60s)
   • MAX_POSITION_SIZE muy alto (riesgo)
   • Condiciones de mercado adversas

Soluciones:
   1. Aumenta CHECK_INTERVAL = 300 (5 min)
   2. Reduce MAX_POSITION_SIZE = 50
   3. Espera 7 más días
   4. Recalibra si persiste
