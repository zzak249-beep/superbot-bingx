RESULTADO:
Versión anterior: 10 señales/mes, win rate ~45%
Versión nueva:    5 señales/mes, win rate ~65%
→ MENOS operaciones pero MEJOR CALIDAD

2. ✅ FILTROS ULTRA-ESTRICTOS
================================================================================

AHORA requiere confirmación de TODOS estos indicadores:

✅ Cruce de liquidez (PDH/PDL) - ENTRADA OBLIGATORIA
✅ Régimen bullish/bearish por EMAs - TENDENCIA
✅ ADX > 25 - FUERZA
✅ MACD bullish/bearish - MOMENTUM
✅ RSI en zona alcista/bajista - NO EXTREMO
✅ Volumen alto - CONFIRMACIÓN
✅ No sobreextendido (BB) - SEGURIDAD
✅ Volatility Stop alineado - TREND CONFIRMATION
✅ Distancia corta de EMA - ENTRADA EFECTIVA

Si CUALQUIERA falla → NO se ejecuta

RESULTADO:
→ Señales muy selectivas
→ Menos falsas alarmas
→ Mejor tasa de ganancia

================================================================================
3. ✅ CONFIANZA CALCULADA
================================================================================

VERSIÓN ANTERIOR:
"Tengo una señal" - Sí/No

VERSIÓN NUEVA:
Cada señal tiene un SCORE de confianza (0-100):

```
Confianza = ADX_score + RSI_score + Volumen_score + Base_score
```

Ejemplo:
- ADX 45: (45/50)*25 = 22.5 puntos
- RSI 55: (55/100)*15 = 8.25 puntos
- Volumen alto: +20 puntos
- Base (pasar todos filtros): +35 puntos
- TOTAL: ~85%

El bot PRIORIZA operaciones por confianza:
- Si hay 2 señales, abre la de 85% antes que la de 70%

RESULTADO:
→ Mejor orden de entrada
→ Menos capital en operaciones débiles

================================================================================
4. ✅ VOLATILITY STOP MEJORADO
================================================================================

VERSIÓN ANTERIOR:

VERSIÓN NUEVA:
Usa AMBOS:

El bot elige el MÁS CONSERVADOR:

RESULTADO:
→ Stop Loss más inteligente

================================================================================
5. ✅ GESTIÓN DE RIESGO MEJORADA
================================================================================

VERSIÓN ANTERIOR:
Tamaño = MAX_POSITION_SIZE / precio

VERSIÓN NUEVA:
Tamaño = (Capital * 2%) / distancia_sl

Basado en riesgo real, no en precio absoluto

Ejemplo:
- Capital: $1000
- Entry: 45,000
- SL: 44,500
- Riesgo: $500
- Tamaño = (1000 * 0.02) / 500 = 0.04 BTC ≈ $1800

Pero limitado a MAX_POSITION_SIZE para seguridad

RESULTADO:
→ Riesgo consistente al 2%
→ No arriesgamos de más
→ Cálculo automático
